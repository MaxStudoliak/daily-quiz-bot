## 💡 Ідея проєкту

**DailyQuiz Bot** — це інтерактивний Telegram-бот, який проводить вікторини з різних тематик:

- 🔬 **Наука** — фізика, біологія, хімія
- 🌍 **Географія** — країни, міста, природа
- 💻 **Програмування** — технології, патерни, мови
- 📜 **Історія** — світова та українська

Кожна гра — 5 питань з 4 варіантами відповідей. Після кожної відповіді бот показує пояснення. Зберігається статистика гравця.

## 🚀 Запуск проєкту

### 1. Клонуйте репозиторій

```bash
git clone https://github.com/YOUR_USERNAME/daily-quiz-bot.git
cd daily-quiz-bot
```

### 2. Встановіть залежності

```bash
npm install
```

### 3. Налаштуйте бота

```bash
cp .env.example .env
```

Відредагуйте `.env`:

```env
BOT_TOKEN=ваш_токен_від_BotFather
```

> 📝 Отримати токен можна у [@BotFather](https://t.me/BotFather) командою `/newbot`

### 4. Запустіть бота

**Режим розробки (з автоперезапуском):**
```bash
npm run watch
```

**Продакшн:**
```bash
npm run build
npm start
```

## 🧠 Архітектурні рішення

- **In-memory sessions** — сесії гравців зберігаються в `Map<userId, UserSession>` без зовнішньої БД
- **Callback queries** — вся навігація через `InlineKeyboard` без текстових команд
- **Stateless questions** — питання зберігаються у статичному масиві, легко розширювати
- **TypeScript strict mode** — повна типізація всіх компонентів
